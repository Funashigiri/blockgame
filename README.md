# blockgame

Воксельная песочница в духе Minecraft на собственном движке, написанном на [Odin](https://odin-lang.org).
Название рабочее.

Что уже есть в игре — [CHANGELOG.md](CHANGELOG.md). Что планируется — [ROADMAP.md](ROADMAP.md).

## Управление

| Клавиша | Действие |
|---|---|
| Мышь | Смотреть по сторонам |
| W A S D | Идти вперёд / влево / назад / вправо (в полёте — лететь) |
| Пробел | Прыжок; в полёте — вверх |
| Пробел дважды быстро | Включить или выключить полёт |
| Shift | В полёте — вниз |
| Ctrl (удерживать) | Бег; в полёте — быстрее |
| Левая кнопка мыши | Сломать блок (держать — ломать дальше) |
| Правая кнопка мыши | Поставить блок (держать — ставить дальше) |
| 1 2 3 4 5 | Выбрать блок: трава, земля, камень, песок, доски |
| Esc | Пауза и меню (ещё раз — вернуться в игру) |
| F11 | Полный экран / окно |

FPS, режим (ходьба или полёт) и выбранный блок показываются в заголовке окна;
в меню паузы FPS виден и в полноэкранном режиме.

Настройки (режим экрана, место и размер окна) хранятся в `%APPDATA%\blockgame\settings.txt`.
Удали этот файл, чтобы вернуть всё как было.

## Сборка (Windows)

Нужны Visual Studio Build Tools (MSVC) и Windows SDK.
Компилятор Odin кладётся в `tools\odin\` (в репозиторий не входит) или берётся из PATH.

```bat
build.bat
build\blockgame.exe
```

## Автотест

```bat
cd build
blockgame.exe --test
```

Игра сама играет с имитацией нажатий клавиш: стоит, прыгает, обегает планету кругом, летает,
ставит блоки и прокапывает шахту до ядра.
Результат каждой проверки — в `test.txt` (PASS / FAIL), виды глазами игрока — в `test_*.png`.
Если что-то не прошло, программа завершается с кодом 1.

## Проверка производительности

```bat
cd build
blockgame.exe --bench
```

10 секунд облёта планеты без ограничения кадров — показывает запас производительности.
`blockgame.exe --bench-vsync` — тот же облёт с привязкой к частоте экрана, как в обычной игре;
считает кадры, пропустившие обновление экрана (их игрок видит как рывок).

Результат — в `bench.txt`, плюс снимки экрана `bench_*.png`.

`build.bat -define:NO_CULLING=true` собирает игру, которая рисует весь мир без отсечения
невидимого, — чтобы сравнить снимки и убедиться, что отсечение ничего видимого не прячет.
